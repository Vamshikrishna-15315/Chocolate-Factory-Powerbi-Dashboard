# 🍫 Chocolate Factory Sales Analysis – Power BI Dashboard

## 📊 Project Overview
This project is an interactive Power BI dashboard developed to analyze sales performance for a chocolate factory. The dashboard provides insights into total sales amount, boxes sold, monthly sales trends, product-wise sales, country-wise sales, and salesperson performance.

## 🎯 Project Objectives
- Analyze monthly sales performance
- Identify top-performing products
- Compare sales across different countries
- Evaluate salesperson performance
- Track total sales amount and boxes sold
- Provide an interactive dashboard for business analysis

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Transformation
- Data Visualization
- Business Intelligence

## 📁 Dataset
The dataset contains chocolate factory sales information used to analyze sales performance across different dates, products, countries, and salespersons.

### Key Data Fields
- Date
- Product
- Country
- Sales Person
- Amount
- Boxes

## 🔄 Data Preparation
The data was prepared using Power Query before creating the dashboard.
- Imported the sales dataset
- Checked data types
- Cleaned and organized the data
- Handled missing values
- Transformed data into analysis-ready format
- Created calculated fields

## 📌 Key Performance Indicators (KPIs)
- Total Sales Amount
- Total Boxes Sold
- Monthly Sales Performance
- Product-wise Sales
- Country-wise Sales
- Salesperson-wise Performance

## 📊 Dashboard Features
### Monthly Sales Trend
Analyzes changes in sales amount over time.
### Product-wise Sales
Compares sales generated by different chocolate products.
### Country-wise Sales
Shows the contribution of different countries to total sales.
### Salesperson Performance
Displays sales generated by individual salespersons.
### Date Filter
Allows users to analyze sales for a selected period.
